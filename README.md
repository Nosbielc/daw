# WebDAW

Uma DAW (Digital Audio Workstation) completa rodando no navegador, sem dependências externas.

## ✨ Funcionalidades

- **Até 16 faixas** de áudio independentes
- **Volume** por faixa com fader visual (dB display)
- **Mute** e **Solo** por faixa
- **Volume Master** com display em dB
- **Transporte**: Play, Stop, Rewind, Record
- **Timeline** com régua de tempo e playhead animado
- **Waveform** visual de cada clipe de áudio
- **Drag & drop** de arquivos de áudio diretamente nas faixas
- **Arrastar clipes** para reposicionar na timeline
- **Menu de contexto** (clique direito) para carregar/remover clipes
- **Atalhos de teclado**: `Space` (Play/Stop), `Home` (Rewind), `Ctrl+T` (Add Track), `R` (Record)
- **Medidores de nível** animados por faixa
- **Design moderno** dark theme com paleta de cores por faixa

## 🚀 Como usar

1. Acesse o site (GitHub Pages)
2. Clique em **Add Track** ou arraste arquivos de áudio para a área de arranjo
3. Carregue áudios via drag & drop ou clique direito → "Carregar arquivo de áudio"
4. Pressione **Play** ou `Space` para reproduzir

## 🛠 Tecnologia

- HTML5 + CSS3 + JavaScript puro (sem frameworks, sem compilação)
- Web Audio API nativa
- Canvas API para waveforms e régua
- 100% offline após carregamento inicial

## 📦 Deploy

Hospede qualquer servidor estático ou GitHub Pages — basta colocar `index.html` na raiz.
